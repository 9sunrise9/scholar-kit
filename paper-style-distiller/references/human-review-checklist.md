# Human Review Checklist

## Mandatory Review Cases

- all innovation dimension outputs
- strong claims with confidence below 0.75
- any leakage warning

## Checklist

1. Is each strong claim backed by matched strong evidence?
2. Is novelty phrasing specific and not overclaimed?
3. Are boundary conditions clearly stated?
4. Is wording sufficiently transformed from source text?
5. Is section-intent-tense usage consistent with profile?

## Decision Labels

- pass
- pass_with_minor_edits
- reject_and_rerun

## Reviewer Notes Format

- item_id
- issue_type
- severity
- fix_suggestion
- approved_by
